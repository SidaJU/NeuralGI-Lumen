# Checkpoint 清单

`runs/<名称>/best.pt` 保存各次训练的最佳权重。

> ⚠️ 命名规则（自本文件建立之日起执行）：
> `<方案>_<数据>_<变体>`，例如 `bprime_mixed_nohist`。
> 新增 checkpoint 必须同时在本文件登记：训练命令、数据、in_dim、用途。

---

## 命名前缀含义

| 前缀 | 方案 | 输入 → 答案 |
|---|---|---|
| `a` | A 纯滤波 | low.in(64条未滤波) → low.gt(64条已滤波) |
| `b*` | B' 滤波+补射线 | low.in(64条未滤波) → **high.gt(256条已滤波)** |
| `b2` / `rayonly` | B'' 纯补射线 | low.in(64条未滤波) → high.in(256条未滤波) |

## 关键教训（血泪）

**① `gt_dir` 曾长期失效（最重要）**

`train.py` 定义了 `--gt-dir` 参数却**从未传给 `ProbeTexelDataset`**，
导致 `b_scheme`、`b_full` 等"以为在训 B'"的模型实际都退化成方案 A。
已修复，现在训练会打印 `方案: B'(...)` 确认。

**② 训练与推理的维度必须一致**

- 带历史 → `in_dim=56`
- `--no-history` → `in_dim=52`（维度被移除，不是填 0）

换模型部署时，必须同步核对 `NSPF_IN_DIM`(cpp) 与 shader stride。

**③ 每次训练都应登记**

本文件就是为了终结"13 个目录说不清谁是谁"的混乱。
