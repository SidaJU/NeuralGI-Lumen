## 0. 为什么需要初始化？

神经网络训练前，权重要有初始值。不能是：

| 初始值 | 后果 |
|---|---|
| **全 0** | 所有神经元输出一样、梯度一样，永远学不会区分（对称失效）|
| **太大** | 信号逐层放大 → 数值爆炸（梯度爆炸）|
| **太小** | 信号逐层衰减 → 最后消失（梯度消失）|

**本文主角：Kaiming 初始化**（何恺明等，2015），专治"后面接 ReLU"的网络。

## 1. 线性层：矩阵 + 偏置

### 1.1 从一维讲起

```
y = a·x + b
```

- `x`：输入（一个数）
- `a`：权重（一个数）
- `b`：偏置（一个数）

### 1.2 多维的形式

```
y = W x + b
```

**关键变化：`a` 从"一个数"变成了"矩阵的一整行"。**

### 1.3 具体例子（2 维输入 → 2 维输出）

```
x = (1, 2)

W = [[2, 0],        ← 2 行 2 列，共 4 个数
     [0, 3]]

b = [1, -1]
```

**对应关系：**

| | 权重（"a"） | 偏置（"b"） | 公式 |
|---|---|---|---|
| 第 1 个输出 | W 的**第 1 行** `[2, 0]` | `1` | `y₁ = 2·x₁ + 0·x₂ + 1` |
| 第 2 个输出 | W 的**第 2 行** `[0, 3]` | `-1` | `y₂ = 0·x₁ + 3·x₂ − 1` |

代入 `x₁=1, x₂=2`：

```
y₁ = 2×1 + 0×2 + 1 = 3
y₂ = 0×1 + 3×2 − 1 = 5

y = (3, 5)
```

> **矩阵有几行 = 有几个输出。**
> **每一行 = 该输出对应的一组权重。**
> **偏置的元素个数 = 输出个数。**

### 1.4 换个矩阵，看"每行是一种看法"

```
W = [[ 1,  1],
     [ 1, -1]]
b = [0, 0]

y₁ = 1×1 + 1×2    = 3      ← 相当于 "x₁ + x₂"（求和）
y₂ = 1×1 + (−1)×2 = −1     ← 相当于 "x₁ − x₂"（求差）
```

**矩阵的每一行定义了一种"看法"（特征）。** 神经网络通过训练学会"该用哪些看法"。

### 1.5 形状约定与参数量

```python
nn.Linear(in_features, out_features)
```

- 权重 `W` 形状：**(out_features, in_features)** —— 输出在前
- 偏置 `b` 形状：**(out_features,)**

**参数量公式**：

```
参数量 = in × out + out
```

例：`Linear(100, 64)` → `100×64 + 64 = 6464`

## 2. 方差是什么（手算）

### 2.1 定义

> **方差 = "这堆数偏离平均值有多远"**

### 2.2 四步计算

以这 5 个数为例：`[2, 4, 4, 4, 6]`

**第 1 步：算平均值**

```
mean = (2+4+4+4+6) / 5 = 4
```

**第 2 步：每个数减平均值**

```
2−4 = −2
4−4 =  0
4−4 =  0
4−4 =  0
6−4 = +2
```

**第 3 步：偏离取平方**

```
(−2)² = 4
0²    = 0
0²    = 0
0²    = 0
(+2)² = 4
```

> **为什么平方？** 不平方的话正负抵消，加起来恒等于 0。平方后全为正，才能累加。

**第 4 步：平方再求平均**

```
Var = (4+0+0+0+4) / 5 = 1.6
std = √1.6 = 1.265
```

### 2.3 另一个量：能量（平方的平均）

```
E[x²] = (2²+4²+4²+4²+6²) / 5 = (4+16+16+16+36)/5 = 17.6
```

- **方差**：先减平均值，再平方，再平均
- **能量**：直接平方，再平均

（Kaiming 的推导用的是"能量"，见第 5 节。）

## 3. PyTorch 的默认初始化：均匀分布

创建 `nn.Linear(...)` 时，PyTorch 会自动填初始值。

**关键事实：默认不是高斯（正态）分布，而是均匀分布。**

### 均匀分布 vs 正态分布

| | 均匀分布 | 正态分布 |
|---|---|---|
| 形状 | 矩形，有**硬边界** | 钟形，**无边界** |
| 极端值 | 不会出现超过 3σ 的值 | 自然出现 3~4σ 的极端值 |

**怎么判断是哪种？** 看有没有"远离中心"的极端值：

```
均匀分布：0 个超过 3σ（被边界卡住）
正态分布：约 0.27% 超过 3σ
```

### 默认值的特点

- 权重均值 ≈ 0 ✅
- 权重**不是** 2/fan_in ❌
- 偏置是**随机小值，不是 0** ❌（这点常被忽略）

## 4. Kaiming 公式：为什么是 `2 / fan_in`

```python
nn.init.kaiming_normal_(weight, nonlinearity="relu")
```

这行让权重方差 = **2 / fan_in**，其中 `fan_in` = 输入维度。

### 4.1 分母 `fan_in`：抵消"求和放大"

线性层是 `n` 项求和（`n = fan_in`）：

```
z = w₁x₁ + w₂x₂ + ... + wₙxₙ
```

若权重方差 = 1：

```
Var(z) = n × Var(W) × Var(x) = n × Var(x)    ← 放大 n 倍！
```

想让输出方差 = 输入方差：

```
n × Var(W) = 1
Var(W) = 1/n          ← 分母的来历
```

> **类比：n 个人每人往池里倒一杯水。想让总量≈一杯，每人只能倒 1/n 杯。**

### 4.2 分子 `2`：预支给 ReLU 的过路费

ReLU 把负数砍成 0。若输入关于 0 对称分布，则**约一半被砍掉**，能量减半：

```
E[ReLU(z)²] ≈ E[z²] / 2
```

若只用 `Var(W) = 1/n`：

```
Var(z) = Var(x)
ReLU 后 = Var(x) / 2      ← 只剩一半，信号逐层衰减！
```

所以先把方差**加倍**：

```
Var(W) = 2 / n

验证：
  Var(z)  = n × (2/n) × Var(x) = 2 × Var(x)   ← 先放大 2 倍
  ReLU 后 = 2 × Var(x) / 2     = Var(x)       ← 砍半后刚好复原 ✓
```

> **类比：路上会被抽走一半，那就寄两倍的量，到了剩下的正好够。**

### 4.3 合起来

```
Var(W) = 2 / fan_in
std(W) = √(2 / fan_in)
```

**例**：`fan_in = 100`

```
Var(W) = 2/100  = 0.02
std(W) = √0.02  ≈ 0.141
```

权重是 ±0.14 附近的小随机数。

## 5. "采样" 而非 "精确赋值"

准确说法是：

> **Kaiming 不是让"这堆权重的方差精确等于 2/fan_in"，
> 而是"从『方差 = 2/fan_in 的正态分布』里随机采样出这些权重"。**

采样结果会在理论值附近**波动**：

```
理论目标: 0.0357（当 fan_in=56）
实测可能: 0.0362        ← 差 1.4%，正常
```

> **类比：掷硬币理论正面 50%，掷 10 次可能得到 6 次（60%）。采样数越多越接近。**

因此权重数量越多，实测方差越接近理论值。

## 6. 完整数值演示（小例子，可手算）

设 `fan_in = 3`，输入 `x = (1, 2, 0.5)`，方差 `Var(x) ≈ 0.69`。

**Kaiming 权重**：`Var(W) = 2/3 ≈ 0.667`，标准差 ≈ 0.816。

随机采样两个输出神经元的权重：

```
W = [[ 0.9,  -0.5,  0.6],      ← 第 1 行（第 1 个输出）
     [-0.7,   0.8,  0.2]]      ← 第 2 行（第 2 个输出）
b = [0, 0]
```

**算 z：**

```
z₁ = 0.9×1 + (−0.5)×2 + 0.6×0.5 = 0.9 − 1.0 + 0.3 = 0.2
z₂ = (−0.7)×1 + 0.8×2 + 0.2×0.5 = −0.7 + 1.6 + 0.1 = 1.0
```

**ReLU：**

```
ReLU(0.2) = 0.2      ← 保留
ReLU(1.0) = 1.0      ← 保留
```

（这个例子里两个都是正数，没被砍。样本多时会趋近一半被砍。）

**多层累积对比：**

| 层数 | `Var(W)=2/n` | `Var(W)=1/n` |
|---|---|---|
| 输入 | 1.0 | 1.0 |
| 第 1 层后 | **≈1.0** ✅ | 0.5 ❌ |
| 第 2 层后 | **≈1.0** ✅ | 0.25 ❌ |
| 第 5 层后 | **≈1.0** ✅ | 0.031 ❌ |
| 第 10 层后 | **≈1.0** ✅ | 0.001 ❌ 消失 |

## 7. 常见激活函数对应的初始化

Kaiming 通过 `nonlinearity` 参数区分：

| 激活 | 方差公式 | 说明 |
|---|---|---|
| **ReLU / Leaky ReLU** | `2 / fan_in` | 砍掉一半，所以要 ×2 |
| **tanh / 线性** | `1 / fan_in` | 不砍，不需要补偿（Xavier）|

**所以**：只有当后面接 ReLU 时，公式里才有那个 2。

---

## 8. 总结

| 问题 | 答案 |
|---|---|
| 默认值是什么分布？ | **均匀分布**，且偏置是随机的（不是 0）|
| 方差怎么算？ | 平均 → 减平均 → 平方 → 再平均 |
| 参数量？ | `in × out + out` |
| 为什么 `2/fan_in`？ | 分母抵消求和放大；分子补偿 ReLU 砍半 |
| 是精确等于吗？ | 不是，是**从该分布采样**，会有波动 |
| 什么时候不用 2？ | 后面不接 ReLU 时（用 `1/fan_in`）|

---

## 附：核心公式卡

```
线性层:        y = W x + b
权重形状:      W: (out, in)
参数量:        in × out + out

方差:          Var(x) = 平均[(x − 平均值)²]
能量:          E[x²] = 平均[x²]
关系:          Var = E[x²] − (E[x])²

Kaiming(ReLU): Var(W) = 2 / fan_in
               std(W) = √(2 / fan_in)

Xavier(线性):  Var(W) = 1 / fan_in
```
