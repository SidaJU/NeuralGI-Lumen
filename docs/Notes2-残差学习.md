# Notes 2：残差学习与 `+x` 的意义

> 通用知识点。不涉及任何具体项目。
>
> 目标：搞懂两件事——
> 1. 为什么要有 `y = x + F(x)` 里那个 `+x`（这是残差学习的**本体**）
> 2. "最后一层归零"在其中扮演什么角色（这是**配件**，不是主体）

---

## 0. 先分清主体与配件

最容易混淆的一点：

| | 是什么 | 地位 |
|---|---|---|
| `y = x + F(x)` 的 **`+x`** | 残差连接 / 捷径（skip connection）| ✅ **核心本体** |
| **最后一层归零** | 一种初始化技巧 | ⚠️ 配件（让起点更稳，去掉也仍是残差学习）|

**没有归零，只要有 `+x`，就仍是残差学习。**
**但去掉 `+x`，就完全不是残差了。**

---

## 1. 公式对比

### 传统（非残差）

```
y = F(x)
```

`F` 直接给出最终结果 —— 网络要从零学会"答案是什么"。

### 残差形式

```
y = x + F(x)
    │   └── 网络学"增量"（该把输入改动多少）
    └────── 输入原封不动地跳过（捷径）
```

**核心变化：网络的目标从"输出答案"变成"输出相对输入的改变量"。**

---

## 2. 为什么需要 `+x`？（三个层次）

---

### 2.1 理由一：信息保底（最直觉）

若网络学坏，`F(x)` 输出垃圾：

```
无 +x:  y = F(x) = 垃圾                 ← 完全被毁
有 +x:  y = x + 垃圾 = 原信息 + 噪声     ← 至少原始信息还在
```

极端情况 `F(x) = 0`：

```
y = x + 0 = x        ← 输出 = 输入，完全无损
```

> **`+x` 提供了一条保底通道：最坏情况就是"什么都不做"，信息不会丢。**

---

### 2.2 理由二：让"什么都不做"变得容易（ResNet 的核心洞察）

#### 退化问题

理论上网络越深越好——多余的层学成"恒等映射"（`y = x`）即可，不该更差。
但**实际上深层网络训练误差反而更高**。

**为什么？** 因为让一堆非线性层（`Linear + ReLU`）去拟合恒等映射 **非常难**。
要经过多次矩阵乘法和非线性截断，最后还要恰好等于输入，需要权重极其精确地配合。

#### 残差如何解决

改成 `y = x + F(x)` 之后：

```
想让整块输出 = 输入
   → 只需 F(x) = 0
   → 而让 F(x) = 0 非常简单：权重趋近 0 即可
```

> **让一堆层拟合"恒等映射"很难；
> 但让一堆层的输出变成 0 很容易。**

这就是残差网络能堆到几百上千层的原因：**每层都可以"选择不干活"（输出 0），而不会破坏前面学到的东西**。

**这个"可以不干活"的选项，正是 `+x` 赋予的。**

---

### 2.3 理由三：梯度的高速公路（数学层面）

反向传播时梯度要穿过所有层。若每层梯度都小，连乘后消失：

```
无 +x:   ∂y/∂x = ∂F/∂x ≈ 0.1
         10 层后: 0.1¹⁰ = 1e-10        ← 消失
```

有 `+x` 时：

```
y = x + F(x)
∂y/∂x = 1 + ∂F/∂x
        ↑
        这个常数 1 就是保底

即使 ∂F/∂x = 0.1：∂y/∂x = 1.1，不会趋近 0
```

> **`+x` 给梯度修了一条绕过所有层的直达公路，那个常数 `1` 保证梯度不会消失。**

---

## 3. 最后一层归零：让捷径在开局"完全生效"

有了 `+x` 之后，归零的作用就很自然了：

```
开局：F(x) = 0（最后一层权重全 0）
   → y = x + 0 = x                 ← 整个网络等价于"不存在"
   
训练中：F(x) 逐渐学到非零值
   → y = x + 一点点修正
```

| | 不归零 | 归零 |
|---|---|---|
| 开局输出 | `x + 随机噪声` | `x`（干净）|
| 相当于 | 一上来就乱改 | 一上来什么都不改 |
| 训练起点 | 离答案远 | **离答案近** |

配合 2.2 节：**归零让"所有层都可以选择不干活"这个特性，在训练第 0 步就完全成立。**

---

## 4. 完整数值例子（A/B 对比）

### 网络结构

```
输入  x = (1, 2)
        ↓
第 1 层  Linear(2,2) → ReLU
        ↓  h
第 2 层  Linear(2,2)          ← 最后一层
        ↓  out_raw
输出   y = x + out_raw        ← 残差连接
```

### 固定第 1 层

```
W1 = [[ 1,   0.5],
      [ 0.5, -1 ]]
b1 = [0, 0]

z1 = W1·x = [1×1 + 0.5×2,   0.5×1 + (−1)×2]
          = [2,            −1.5]

h = ReLU(z1) = [2, 0]         ← −1.5 被砍成 0
```

---

### 场景 A：最后一层归零

```
W2 = [[0, 0],
      [0, 0]]
b2 = [0, 0]

out_raw = [0, 0]

y_A = (1, 2) + (0, 0) = (1, 2)
```

**输出 = 输入。**

---

### 场景 B：最后一层不归零（随机值）

```
W2 = [[ 0.5, −0.3],
      [ 0.2,  0.4]]
b2 = [0.1, −0.2]

out_raw = [0.5×2 + (−0.3)×0 + 0.1,   0.2×2 + 0.4×0 + (−0.2)]
        = [1.0 + 0.1,                0.4 − 0.2]
        = [1.1,  0.2]

y_B = (1, 2) + (1.1, 0.2) = (2.1, 2.2)
```

**输出被随机扰动了。**

---

### 对比（设正确答案为 `(1.1, 2.1)`）

**误差 = 输出与答案的距离**

```
A: √[(1 − 1.1)² + (2 − 2.1)²]     = √0.02  = 0.141
B: √[(2.1 − 1.1)² + (2.2 − 2.1)²] = √1.01  = 1.005
```

| | 输出 | 误差 | 相对 |
|---|---|---|---|
| **A 归零** | (1, 2) | **0.141** | 1 倍 ✅ |
| B 不归零 | (2.1, 2.2) | 1.005 | **7.1 倍** ❌ |

### 为什么差这么多？

**理想增量 = 答案 − 输入 = (0.1, 0.1)**

| | 开局增量 | 目标增量 | 需要调整 |
|---|---|---|---|
| **A** | (0, 0) | (0.1, 0.1) | **+0.1**（很小）|
| B | (1.1, 0.2) | (0.1, 0.1) | **−1.0, −0.1**（大，还要往回退）|

**A 只需学一个小增量；B 得先撤销随机值，再学。**

### 从 loss 看稳定性

```
MSE loss = (y − target)²

A: 0.141² = 0.020
B: 1.005² = 1.010        ← 大 50 倍
```

loss 大 50 倍 → 梯度也大约大 50 倍 → 更新幅度大 → 大学习率下容易训飞。

---

## 5. 残差基准的选择（当输入输出维度不同时）

前面例子里输入和输出都是 2 维，可以直接 `y = x + F(x)`。

**但若两者维度不同呢？**

```
x    : 100 维
F(x) : 3 维

x + F(x)   →  维度不匹配，无法相加
```

### 通用原则

> **残差基准必须是"与输出同性质、同维度"的那个量。**

三种常见情况：

| 情况 | 做法 | 例子 |
|---|---|---|
| **A. 同维度** | 直接用输入 | `y = x + F(x)`（ResNet 常规做法）|
| **B. 输入维度更大，输出是其中一部分** | 取出输入中**对应输出的那一段** | 见下方说明 |
| **C. 维度完全不匹配** | 用一个线性变换把 `x` 投影到输出维度 | `y = W_s·x + F(x)`（ResNet 的 shortcut 投影）|

### 情况 B 的含义

若输入是一个"打包的特征向量"，其中某几维恰好就是"待改进的量"，那么：

```
基准 = 输入中代表"待改进的量"的那几维
输出 = 该基准 + 网络算出的修正量
```

**物理意义**：

```
输出 = 待改进的原始值 + 网络认为该调整多少
     = 改进后的值
```

**这样做为什么合理？** 因为输入和输出是**同一个物理量的不同状态**（比如"含噪版本"与"干净版本"），让网络学"改多少"比学"绝对值"容易得多 —— 尤其当理想增量很小时。

---

## 6. 一句话总结

| 问题 | 答案 |
|---|---|
| **`+x` 是什么？** | 让输入直达输出的捷径 |
| **为什么需要它？** | ① 信息保底 ② 让"什么都不做"变容易（只需 `F=0`）③ 梯度高速公路（导数含常数 1）|
| **归零的作用？** | 让这条捷径在**开局**完全主导（`F=0`，输出 = 输入）|
| **归零 vs `+x` 谁更重要？** | **`+x` 是本体**，归零只是让它开局更稳的配件 |
| **维度不同怎么办？** | 取输入中与输出"同性质同维度"的那部分作基准；或用线性投影 |

---

## 附：核心公式卡

```
残差块:        y = x + F(x)
传统块:        y = F(x)

梯度:          ∂y/∂x = 1 + ∂F/∂x
                      ↑ 常数 1 = 保底，防止梯度消失

初始化建议:    F 的最后一层权重、偏置初始化为 0
               → 开局 F(x)=0，y = x

维度处理:      同维度 → 直接用 x
               输入含输出段 → 取该段
               维度不匹配 → 线性投影 W_s·x
```
