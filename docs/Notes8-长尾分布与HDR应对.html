Notes 8：长尾分布与 HDR 应对

probe radiance 的长尾问题 —— 从现象、危害到三层措施（含代码如下落）

1. 长尾是什么（对什么数据的判断）

判断对象：probe radiance（屏幕探针的辐射亮度，HDR 线性值）。

实测统计（probe_dataset.py:68 / losses.py:5-6）：

分位值含义
p50（中位数）0.029一半的格子亮度 ≤ 0.029（很暗）
p992.6只有 1% 的格子 > 2.6
max15.75最亮格子是中位数的 543 倍
生活类比：社会收入 —— 大部分人收入普通，极少数富豪收入极高，把分布右边拉出长尾。

2. 危害：为什么长尾 + MSE 会毁掉训练

MSE 用平方误差，量级差异会被平方放大：

样本radiance平方误差（∝自身²）
暗部（p50）0.029≈ 0.00084
亮部（max）15.75≈ 248
248 / 0.00084 ≈ 29.5 万倍
→ 亮部一个样本的误差，顶暗部 29.5 万个样本。
→ losses.py:7-8 原话："亮部样本虽然只占 1%，但其平方误差会主导整个 loss，导致网络只顾拟合亮部、暗部全部学废。"

后果：GI 的主要价值是照亮暗部，但网络把全部容量拿去伺候那 1% 的亮部 → 暗部/中间调全学不好。

3. 措施①：log1p 压缩动态范围

probe_dataset.py:65-71

def log_normalize(x):
    return np.log1p(np.maximum(x, 0.0)).astype(np.float32)

4. 措施②：relative L2（除自身亮度）

losses.py:26-54

denom = pred.detach() ** 2 + self.eps      # stop-gradient
loss  = (pred - target) ** 2 / denom
样本机制效果
亮部分母大 → 误差被缩小不再主导 loss
暗部分母小 → 误差被放大网络必须认真学
losses.py:17："等价于对所有亮度量级'一视同仁'，这正是 HDR 需要的。"

代码自带的演示（python losses.py）

构造样本：pred=[0.05, 3.0]、gt=[0.10, 3.2]（暗部相对错 50%，亮部错 6%）：

损失暗部贡献亮部贡献
MSE5.9%94.1%（亮部主导）
relative L284.7%15.3%（主导权反转）
注意：这个演示里暗部从 6% 涨到 85% —— 说明 relative L2 的放大可能"过头"（暗部主导）。
这正是需要 eps 来平衡的原因（见下节）。

5. 措施③：eps 选型（我们基于自己数据的调优）

losses.py:37-43 记录了依据（用真实 GT 统计，非拍脑袋）：

log1p(gt)² 分位数：p25=0.000, p50=0.003, p95=0.817, p99=1.813

eps=0.01 (NIV 原值) → 暗部放大 76.7x，亮部 1.21x，比值 63
eps=0.1             → 暗部放大  9.7x，亮部 1.09x，比值 8.9   ← 选这个
eps=0.5             → 暗部放大  2.0x，亮部 0.76x，比值 2.6
eps暗部放大亮部放大暗/亮比值评价
0.01（NIV 原值）76.7x1.21x63暗部独大
0.1（我们选）9.7x1.09x8.9✅ 平衡（亮部≈1、暗部适度）
0.52.0x0.76x2.6退化回 MSE
额外考虑（losses.py:42-43）：25% 的格子是背面（值恒为 0） —— eps 太小会让这些样本 loss 饱和到 1 导致梯度消失；0.1 兼顾暗部学习与零值样本稳定性。

6. ★ 实测对照实验：MSE vs relative L2

本节已于 2026-10-16 补跑实测对照实验。
此前只有理论预期（losses.py:58：MaskedMSELoss "作为对照基线，预期效果会明显差于 relative L2"）。 实测结果与这个预期不同 —— 两者差异 <0.2%（见下方）。
教训：代码注释里的"预期"不能当结论，必须用实验验证。

怎么解读（重要）

真正解决长尾的是 log1p，不是 relative L2。
因为数据已经 log1p 压缩过（动态范围从 543 倍压到 O(1)）， relative L2 的"再归一化"属于收益递减 —— 这正好印证了 Notes3 第 8 节的预判：
"如果数据已经做过归一化，relative L2 的边际收益就变小了。"

所以 relative L2 的定位是稳健性保险（Notes3 第 9 节）：防 outlier、保护小值样本、换数据时不失效 —— 而不是实测上的精度提升。
对外表述（基于实测更新）：
"针对 radiance 的长尾分布（p50=0.029、max=15.75），采用 log1p 压缩动态范围（平方误差量级差 29.5 万倍 → 9,724 倍）+ relative L2 作为稳健性损失；对照实验显示：在已 log1p 的数据上，relative L2 与 MSE 的各分区误差差异 <0.2%， 说明收益主要来自 log1p，而非损失函数的归一化。"
不要说："relative L2 显著提升了暗部质量" —— 实测不支持（仅 0.2%）。
