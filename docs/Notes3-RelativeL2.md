# Notes 3：Relative L2 损失函数

> 通用知识点。
>
> 目标：搞懂 relative L2 如何解决 MSE 在长尾分布上的偏斜问题，以及 `eps` 怎么选。
>
> 前置：Lesson1（MSE 损失函数）

---

## 1. 回顾：MSE 的问题

```
L_MSE = (pred − gt)²
```

问题：**大数值样本的误差天然大，平方后主导 loss**。

三个样本的对比：

| 样本 | gt | pred | 平方误差 | MSE 贡献 |
|---|---|---|---|---|
| A（暗）| 0.1 | 0.15 | 0.0025 | 0.95% |
| B（中）| 1.0 | 0.90 | 0.0100 | 3.81% |
| C（亮）| 4.0 | 3.50 | 0.2500 | **95.24%** |

**C 一个样本吃掉 95%** → 网络只顾拟合亮部，占多数的暗部被忽略。

---

## 2. relative L2 的公式

```
L_rel = (pred − gt)² / (pred² + eps)
                      └────┬────┘
                      比 MSE 多的分母
```

- 分子：和 MSE 完全一样（误差的平方）
- 分母：**该样本自身预测值的平方** + 一个小的 `eps`

**核心：每个样本按"自己的亮度"归一化。**

---

## 3. 手算一遍（同样 3 个样本，eps = 0.1）

| 样本 | 平方误差 | 分母 `pred² + 0.1` | relative L2 |
|---|---|---|---|
| A | 0.0025 | 0.15² + 0.1 = **0.1225** | 0.0025 / 0.1225 = **0.0204** |
| B | 0.0100 | 0.90² + 0.1 = **0.9100** | 0.0100 / 0.9100 = **0.0110** |
| C | 0.2500 | 3.50² + 0.1 = **12.3500** | 0.2500 / 12.3500 = **0.0202** |

总和 = 0.0516

### 贡献对比

| 样本 | MSE 贡献 | **relative L2 贡献** | 变化 |
|---|---|---|---|
| A（暗）| 0.95% | **39.6%** | ↑ 约 40 倍 |
| B（中）| 3.81% | **21.3%** | ↑ 约 5.6 倍 |
| **C（亮）** | **95.24%** | **39.2%** | ↓ 到约 1/2.4 |

> **主导权从亮部重新分配给暗部。**

---

## 4. 为什么除一下就管用？

看分母的量级差：

| 样本 | pred | 分母 | 效果 |
|---|---|---|---|
| A（暗）| 0.15 | **0.12** | 除数小 → 结果被**放大** |
| C（亮）| 3.50 | **12.35** | 除数大 → 结果被**缩小** |

**两者分母差约 100 倍**，而这正好抵消了它们平方误差的 100 倍差距。

> **核心思想**：亮部误差大是"应该的"（因为它本来就亮）。除掉自身亮度后，大家站在同一条起跑线上。

### 类比

```
MSE:          比绝对值 —— 年薪 100 万捐 1 万，和年薪 10 万捐 1 万，"数字"一样
relative L2:  比相对值 —— 前者捐了 1%，后者捐了 10%，后者"相对"更好
```

我们要优化的是"**相对做得好不好**"，不是"绝对差多少"。

---

## 5. eps 是干什么的？

当 `pred` 很小（接近 0）时，分母 ≈ `eps`。**eps 决定了暗部能被放大多少倍。**

### eps 太小（例：0.001）

```
A: 0.0025 / (0.0225 + 0.001) = 0.106        ← 被放大 42 倍
C: 0.2500 / (12.25 + 0.001)  = 0.0204

暗部彻底主导 → 亮部崩
```

### eps 太大（例：10）

```
A: 0.0025 / (0.0225 + 10) = 0.00025
C: 0.2500 / (12.25 + 10)  = 0.0112

分母被 eps 主导，所有样本除数差不多 → 退化回 MSE
```

### 结论

> **eps = "暗部放大倍数"的上限旋钮**
>
> - 太小 → 暗部无限放大，亮部崩
> - 太大 → 退化回 MSE，亮部重新主导
> - 合适 → 暗部适度加权，亮部保持原样

---

## 6. 为什么用 `pred²` 而不是 `gt²`？

这是 NIV 论文的做法，关键是 **stop-gradient**：

```python
denom = pred.detach() ** 2 + eps
#            ↑ 从计算图里"摘出来"，不参与梯度
```

**为什么需要 detach？**

- 让分母在每一步优化中**表现得像个常数**
- 梯度只从分子（误差）传，优化方向清晰
- 不 detach 的话分母也要求导，公式复杂且可能不稳定

> **`detach()` = 让分母"只当尺子，不参与调整"。**

---

## 7. eps 怎么选？（真实数据扫描示例）

用一批真实数据（p50=0.016 代表暗部，p95=0.908 代表亮部）扫描：

| eps | 暗部放大 | 亮部放大 | 暗/亮比值 | 评价 |
|---|---|---|---|---|
| 0.001 | 57.40 | 1.10 | 52.2 | 暗部极度主导，亮部崩 |
| 0.010 | 37.85 | 1.09 | 34.8 | NIV 原值，仍偏暗 |
| 0.050 | 15.06 | 1.04 | 14.4 | |
| **0.100** | **8.59** | **0.99** | **8.7** | ✅ 较平衡 |
| 0.200 | 4.62 | 0.90 | 5.1 | |
| 0.500 | 1.94 | 0.71 | 2.7 | 退化回 MSE |

### 选型原则

1. **亮部放大应接近 1** —— 既不压制也不放纵（上表 eps=0.1 时亮部 = 0.99 ✅）
2. **暗部放大 5~15 倍** —— 足以让占多数的暗部得到关注，又不至于独大
3. **考虑零值样本** —— 若数据里有很多 0（如背面、无信号），eps 不能太小，否则分母趋 0 会爆

### 实用方法

```
1. 统计数据的 p50（暗部代表）和 p95（亮部代表）
2. 扫描 eps，算 1/(p50+eps) 和 1/(p95+eps) 的比值
3. 选"亮部放大 ≈ 1、暗部放大 5~15 倍"的那个 eps
```

---

## 8. ⚠️ 局限：它没那么神

**实测改善往往是温和的**，不是颠覆性的。

示例（真实数据）：

| | 最亮 10% 的贡献 |
|---|---|
| MSE | 37.9% |
| relative L2 (eps=0.1) | **31.7%** |

只降了 6.2 个百分点。

### 为什么？

**如果数据已经做过归一化（如 `log1p`），动态范围已被压缩，relative L2 的边际收益就变小了。**

| 域 | 暗部(0.1) | 亮部(4.5) | 平方后比值 |
|---|---|---|---|
| 线性域 | 0.1 | 4.5 | **2000 倍** |
| log1p 后 | 0.095 | 1.704 | **322 倍** |

`log1p` 已经把 2000 倍压到 322 倍，relative L2 是在此基础上再压 → 收益递减。

> **若直接用线性域（不做 log1p），relative L2 的价值会大得多。**

---

## 9. 那还有必要用吗？

**有，但定位是"稳健性保险"而非"救命稻草"：**

| 价值 | 说明 |
|---|---|
| **防 outlier** | 极端样本的误差平方可能极大，会主导梯度 |
| **保护小值样本** | 小值往往占多数面积，视觉/体验上更重要 |
| **更稳健** | 换数据、换动态范围时不会突然失效 |

---

## 10. 一句话总结

| 问题 | 答案 |
|---|---|
| **公式？** | `(pred−gt)² / (pred² + eps)` |
| **比 MSE 多了什么？** | 除以自身亮度平方 |
| **解决了什么？** | 亮部主导 loss → 主导权重新分配 |
| **eps 太小？** | 暗部独大，亮部崩 |
| **eps 太大？** | 退化回 MSE |
| **为什么 detach？** | 让分母只当尺子，不参与求导 |
| **局限？** | 若数据已归一化，改善是温和的 |

---

## 附：公式卡

```
MSE:          L = (pred − gt)²

Relative L2:  L = (pred − gt)² / (pred.detach()² + eps)
                                    ↑ stop-gradient

分母作用:     按自身亮度归一化
              pred 大 → 除数大 → 误差被缩小
              pred 小 → 除数小 → 误差被放大

eps 作用:     暗部放大倍数的上限
              eps ↓ → 暗部放大 ↑（过小时暗部独大）
              eps ↑ → 退化回 MSE

选型口诀:     亮部放大 ≈ 1，暗部放大 5~15 倍
```
