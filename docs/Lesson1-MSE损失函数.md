# Lesson 1：MSE 损失函数

> 通用知识点。
>
> 目标：搞懂 MSE 是什么、怎么算、以及它在什么数据上会出问题。

---

## 1. 什么是 MSE

**MSE = Mean Squared Error = 均方误差**

### 公式

```
MSE = (1/N) × Σ (predᵢ − gtᵢ)²
```

- `predᵢ`：第 i 个样本的预测值
- `gtᵢ`：第 i 个样本的真值（ground truth）
- `N`：样本总数

### 计算三步

| 步骤 | 操作 |
|---|---|
| ① | 每个样本：`预测值 − 真值` = 误差 |
| ② | 误差**取平方** |
| ③ | 所有样本的平方误差**求平均** |

> **"均方误差"四个字拆解**：
> 均 = 平均，方 = 平方，误差 = 预测与真值的差

---

## 2. 为什么要平方？

### 理由一：避免正负抵消

```
样本 A 误差 = +0.5
样本 B 误差 = −0.5

直接相加:  0.5 + (−0.5) = 0      ← 看起来完美，其实两个都错
平方相加:  0.25 + 0.25  = 0.5    ← 真实反映误差大小
```

这和"方差要平方"是同一个道理。

### 理由二：放大大误差（双刃剑）

```
误差 0.1  →  平方 0.01
误差 0.5  →  平方 0.25

0.5 是 0.1 的 5 倍
但 0.25 是 0.01 的 25 倍   ← 差距被放大了
```

**这个"放大"在多数情况是优点（重罚大错），但在某些数据上会成为灾难。**

---

## 3. 具体例子（手算）

假设模型对 3 个像素的预测：

| 样本 | 真值 gt | 预测 pred | 误差 | 平方误差 |
|---|---|---|---|---|
| **A（暗）** | 0.1 | 0.15 | −0.05 | **0.0025** |
| **B（中）** | 1.0 | 0.90 | +0.10 | **0.0100** |
| **C（亮）** | 4.0 | 3.50 | +0.50 | **0.2500** |

**算 MSE：**

```
MSE = (0.0025 + 0.0100 + 0.2500) / 3
    = 0.2625 / 3
    = 0.0875
```

### 关键：看"贡献占比"

| 样本 | 平方误差 | 占总 loss 比例 |
|---|---|---|
| A（暗）| 0.0025 | **0.95%** |
| B（中）| 0.0100 | **3.81%** |
| **C（亮）** | 0.2500 | **95.24%** ✅ |

> **一个亮样本吃掉了 95% 的 loss。**

---

## 4. 这会导致什么后果？

网络训练的唯一目标：**让总 MSE 尽量小**。

对比两个改进行动的收益：

| 行动 | loss 变化 | 收益 |
|---|---|---|
| 把 C 的误差 0.50 → 0.10 | 0.2625 → 0.0725 | **降 72%** |
| 把 A 的误差 0.05 → 0.01 | 0.2625 → 0.2610 | 降 0.6% |

**优化亮部的收益是优化暗部的 100 倍以上。**

### 结果

```
亮部：拟合得很准      ✅
暗部：几乎没被优化    ❌ 噪点、误差全部保留
```

**但暗部往往占了样本的绝大多数。**

---

## 5. 平方让问题更严重：对比 MAE

**MAE（平均绝对误差）** 不平方，只取绝对值：

```
MAE = (1/N) × Σ |predᵢ − gtᵢ|
```

同样的例子：

| 样本 | 误差 | MSE 贡献（平方）| MAE 贡献（不平方）|
|---|---|---|---|
| A | 0.05 | 0.95% | **7.69%** |
| B | 0.10 | 3.81% | **15.38%** |
| C | 0.50 | **95.24%** | **76.92%** |

**平方把亮部的主导从 77% 推高到 95%。**

> **平方 = 给大误差加权。**
> 如果某些样本的误差天然就大（比如数值本身大），平方会让它们彻底主导。

---

## 6. 什么样的会触发这个问题？

**两个条件同时成立时，MSE 会出问题：**

### 条件一：数据动态范围大（长尾分布）

```
大部分样本数值很小
极少数样本数值极大
```

典型例子：

| 领域 | 情况 |
|---|---|
| **HDR 图像 / 光照** | 大部分暗，少数高光极亮 |
| **深度图** | 大部分近处，少数极远 |
| **金融数据** | 大部分小额，少数巨额 |
| **音频** | 大部分安静，少数爆音 |

### 条件二：大数值样本的误差也大

这通常是**自然结果** —— 因为：

```
数值 4.0 的样本，误差可能到 0.5
数值 0.1 的样本，误差可能只有 0.05
```

**平方后：0.25 vs 0.0025 → 100 倍差距**

---

## 7. 定量判断方法

想知道你的数据上 MSE 有没有问题，跑这个统计：

```
1. 算每个样本的平方误差
2. 按样本自身的数值（或真值）从大到小排序
3. 看"最大的 X% 样本"贡献了总 loss 的百分之多少
```

### 判读

| 最亮 10% 贡献 | 判断 |
|---|---|
| ≈10% | 健康，各样本公平 |
| 20~30% | 轻微偏斜，可考虑处理 |
| **>35%** | ⚠️ 严重偏斜，MSE 不合适 |
| >50% | ❌ 极端，必须换损失或归一化 |

> **基准线**：如果完全公平，最亮 10% 应该只贡献 10%。

---

## 8. MSE 本身是"坏"的吗？

**不是。它只是不适合某些场景。**

### MSE 的优点

| 优点 | 说明 |
|---|---|
| **数学性质好** | 凸函数、处处可导、梯度简单（`2×(pred−gt)`）|
| **理论最优** | 噪声为高斯分布时，MSE 等价于最大似然估计 |
| **计算快** | 就是平方求和取平均 |
| **收敛稳** | 梯度随误差减小而减小，不会在最优附近震荡 |

### MSE 适合什么

- ✅ 数据分布均匀
- ✅ 无极端 outlier
- ✅ 每个样本同等重要
- ✅ 噪声是高斯白噪声

### MSE 不适合什么

- ❌ 长尾分布（大部分小值 + 极少数大值）
- ❌ 大值样本误差天然大
- ❌ 小值样本占多数且同样重要

---

## 9. 缓解方案

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **① 归一化数据** | 先压缩动态范围（如 `log1p`）| 简单、通用 | 治标，若范围仍大则不够 |
| **② 换损失函数** | 用相对误差（如 relative L2）| 从根本解决 | 需调超参（eps）|
| **③ 样本加权** | 手动给小值样本更高权重 | 灵活 | 权重难定，不优雅 |

**实践中通常 ①+② 组合使用。**

---

## 10. 一句话总结

| 问题 | 答案 |
|---|---|
| **MSE 是什么？** | 误差平方后的平均值 |
| **为什么平方？** | 避免正负抵消 + 放大大误差 |
| **有什么隐患？** | 大数值样本误差天然大，平方后主导 loss |
| **典型后果？** | 网络只顾拟合少数大值样本，忽略占多数的小值样本 |
| **怎么判断有问题？** | 最亮 10% 若贡献 >35% 的 loss，就要警惕 |
| **怎么办？** | 归一化数据 + 换用相对误差损失 |

---

## 附：公式卡

```
MSE   = (1/N) Σ (pred − gt)²
MAE   = (1/N) Σ |pred − gt|
RMSE  = √MSE                      （还原到原量纲，便于解读）

MSE 的梯度（对 pred）:
  ∂L/∂pred = 2×(pred − gt) / N
             ↑ 误差越大，梯度越大 —— 所以大误差主导更新

公平基准:
  若各样本贡献相同，前 X% 的样本应贡献 X% 的总 loss
```
